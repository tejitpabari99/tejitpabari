## Verdict at review time: NEEDS_CHANGES

Findings, all scoped to SP06-owned files:

1. `hostedLiveSlugs()` in `scripts/generate-sitemap.mjs` (SP06 Task 5) derived hosted `/live`
   slugs from a raw directory scan rather than from SP04's `HOSTED_LIVE_PAGES` registry —
   would have emitted a bogus `/projects/sample-project.test/live` sitemap entry once Task 18's
   test file landed.
2. `readCollection()` in `scripts/generate-og-cards.mjs` (SP06 Task 4) accepted a frontmatter
   `slug` with no check against the filename — a path-traversal / arbitrary-file-write primitive
   in build tooling running via `prebuild`.
3. `scripts/generate-sitemap.mjs`'s `<loc>` interpolation was unescaped XML.
4. The three vendored Montserrat `.ttf` files (SP06 Task 3) have no committed checksum or
   license/provenance record — sourced via the third-party `gwfh.mranftl.com`
   (google-webfonts-helper) mirror rather than fetched directly from Google Fonts.

(SP06's own `check-no-forms.sh` bypass and `liveUrl` validation findings are the same two
Security must-fixes recorded against SP04-owned files in the combined review — `vite.config.ts`
and `scripts/check-no-forms.sh` are not SP06-owned, so they aren't re-listed here.)

## Resolution

All remediated on `website-revamp`, same commits as the combined review:

- Finding 1 → `30b6abb` `fix(seo): derive hosted live slugs from the registry, not a directory scan`
- Finding 2 → `e0f3939` `fix(security): reject traversal and mismatched slugs in OG card generation`
- Finding 3 → `339c703` `fix(security): XML-escape slugs interpolated into sitemap.xml <loc>`
- Finding 4 → **not remediated.** Stays open as a recommendation, not a blocker (build-time only,
  processed by memory-safe Rust `satori`/`@resvg/resvg-js`, never served to visitors). Carried
  forward to the initiative `README.md`'s "Still requires the owner" section: confirm or replace
  the font provenance with a checksummed, licensed copy.
